# 닿음 (Dahum)
### AI 기반 가족 보안 서비스

스마트폰 앱 목록 이미지를 분석해 의심 앱을 탐지하고, 복잡한 보안 정보를 사용자와 보호자가 이해하기 쉬운 언어로 안내하는 AI 기반 가족 보안 서비스입니다.

## 02. Background

기존 보안 서비스는 악성 앱이나 위험 요소를 탐지하는 기능에는 강점이 있지만, 보안 지식이 부족한 사용자는 왜 위험한지, 무엇을 해야 하는지 이해하기 어렵다는 문제가 있었습니다.

특히 디지털 보안에 익숙하지 않은 부모님 세대가 단순한 위험 알림만으로 적절한 대응을 판단하기 어렵다는 점에 주목했습니다.

닿음은 단순한 위험 탐지를 넘어, 위험 정보를 이해하고 실제 대응 행동으로 연결하는 것을 목표로 기획했습니다.

## 03. Key Features

- **이미지 기반 앱 정보 추출**: 스마트폰 앱 목록 이미지를 OCR로 분석
- **의심 앱 탐지**: 추출한 패키지명을 기반으로 악성 앱 데이터 조회
- **AI 분석 결과 제공**: 분석 정보를 사용자가 이해하기 쉬운 언어로 안내
- **보호자 대응 가이드**: 보호자에게 상황별 대응 정보 제공

## 07. Troubleshooting

### CORS 및 API 데이터 구조 불일치

**문제 상황**
- Postman에서는 정상적으로 응답하던 API가 프론트엔드에서 CORS 오류로 실패
- 서버 간 요청·응답 데이터 형식이 달라 분석 결과가 화면까지 전달되지 않는 문제 발생

**해결 과정**
- 프론트엔드부터 백엔드, OCR, AI 서버까지 요청 흐름을 단계별로 확인
- Postman과 브라우저 개발자 도구를 활용해 요청 및 응답 추적
- CORS 설정과 데이터 인터페이스 조정

**결과**
- 이미지 업로드부터 AI 분석 결과 출력까지 이어지는 전체 서비스 흐름을 연결하고 통합 테스트 진행

## 08. Retrospective

기획과 UI/UX에 머무르지 않고 데이터 전처리, 외부 API 연동, 백엔드와 AI 서버 연결까지 경험하며 서비스 구현 과정을 이해할 수 있었습니다.

특히 개별 기능이 정상적으로 동작하는 것과 하나의 서비스로 통합되어 동작하는 것은 다르다는 점을 배웠습니다. 다시 프로젝트를 진행한다면 개발 초기부터 API 명세와 데이터 형식을 먼저 정의하고 기능별 테스트를 거쳐 통합하는 방식으로 개선하고 싶습니다.
